📌 Contextualização

O acesso aos dados da Câmara dos Deputados pode ser complexo e pouco intuitivo para grande parte da população. Eleitores, professores e jornalistas enfrentam dificuldades para localizar e interpretar informações relevantes, muitas vezes dispersas e sem uma visualização estruturada.

Centralizar e simplificar o acesso aos dados da Câmara dos Deputados, tornando a consulta mais clara e acessível.

Scrum com 3 sprints de 3 semanas, com revisão ao final de cada ciclo para melhorias contínuas.

👨‍💻 Minha atuação

Atuei como Product Owner, auxiliando na definição de requisitos, organização do GitHub, estruturação das entregas e alinhamento com o cliente.

📊 Resultados obtidos

Aplicação funcional que permite a visualização simplificada de dados públicos da Câmara dos Deputados, facilitando o entendimento por diferentes perfis de usuários.

Sistema de Ordem de Serviço
PHP MySQL HTML CSS JavaScript Bootstrap
📌 Contextualização

O projeto foi desenvolvido em equipe com foco na criação de um sistema de gerenciamento de ordens de serviço para demandas de TI, facilitando o controle de solicitações técnicas dentro de uma organização.

🎯 Objetivo

Desenvolver uma aplicação para cadastro, visualização e gerenciamento de serviços técnicos, permitindo abertura, aceitação e conclusão de ordens de serviço.

⚙️ Metodologia

Metodologia Scrum aplicada em aproximadamente 4 sprints, com desenvolvimento incremental e revisões por etapa.

🧩 Funcionalidades principais

Cadastro de serviços, gestão de solicitações, aceitação de ordens por técnicos, atualização de status e controle de valores e entregas.

👨‍💻 Minha atuação

Atuei no desenvolvimento do front-end, organização da estrutura de dados, integração com banco de dados e implementação da lógica do painel administrativo, incluindo gestão de serviços e usuários técnicos.

📊 Resultados obtidos

Sistema funcional de ordens de serviço capaz de gerenciar demandas técnicas de forma estruturada, melhorando o controle de solicitações e a organização do fluxo de atendimento da equipe.
